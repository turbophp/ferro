# SPEC §23.4 refusal corpus (chaos case 13's offline half; slice M6-F3).
#
# Every line must be REFUSED, by exactly the rule named in the last column. `tests/corpus_it.rs`
# runs it, and asserts that every validator rule, every ORIGIN refusal and every address row is
# exercised by at least one line here.
#
# Format: <kind> <context> <input> <expected>, whitespace-separated. In <input>: \xHH is a byte,
# \s a space, \\ a backslash, \e the empty string. The fixture upstreams are
# `ferro_http::fuzzing::fixture_env()`:
#   root     https://api.example.com          every default
#   api      http://127.0.0.1:9200            ALLOW_PATHS=/api/,/v1  ALLOW_METHODS=GET,POST,patch
#                                             PASS_HEADERS=X-Forwarded-For  ADDRESS_CLASSES=loopback
#   params   https://[2001:db8::1]:8443       PATH_PARAMS=allow  ALLOW_PATHS=/a;b/,/x
#   utf8     https://wiki.example.org         PATH_ENCODING=utf8  ALLOW_PATHS=/w/
#   attach   https://pay.example.com          attached Authorization + X-Api-Key, ATTACH_POLICY=refuse
#   override https://pay.example.com:8443     the same set, ATTACH_POLICY=override, MAX_BODY_BYTES=100
#   uidonly  https://internal.example.com     ALLOW_UIDS=2000,2001
# The request is sent as peer uid 1000.
#
# Kinds:
#   target <upstream> <target> <rule>         method GET, no headers
#   method <upstream> <method> <rule>         a target the upstream accepts
#   header <upstream> <name>=<value> <rule>   one header (split at the FIRST '=')
#   origin-field <upstream> <origin> <rule>   the request's `origin` field
#   upstream <name> <uid|none> <rule>
#   body <upstream> <length> <rule>
#   origin - <ORIGIN> <OriginError>           configuration-time ORIGIN parse
#   address <classes|meta> <ip> <label>       ADDRESS_CLASSES (or `meta`: public + ALLOW_METADATA=1)
#   config <https|http> <KEY=VALUE> <KEY>     one key on a fresh upstream disables it, naming KEY
