# C1g: `quote()` on the MySQL family — the alias columns reach their controls, and upstream's family-specific directories run

**Date:** 2026-10-02 · **Slice:** M2-C1g · **Runner:** `testkit/laravel-suite.sh`, as C1f's columns
(`docs/laravel-suite/2026-10-02-c1f-mysql-results.md`), plus two new allowlists:
`testkit/laravel/allowlist-mysql.txt` (upstream's `tests/Integration/Database/MySql`) and
`allowlist-mariadb.txt` (`…/MariaDb`).

**What changed underneath (SPEC §22.2 (cc)):** MySQL and SQLite pools now advertise
`literals_are_standard`, and `FerroPdoShim::quote()` works on every family — built NOT from that
bit (the adversarial review showed a pool-level bit can describe a different session, and a literal
built from it broke out) but from forms that mean the same bytes in every escape mode: `'` doubled
for a string with no backslash, `E'…'` (PostgreSQL) or `_utf8mb4 X'<hex>'` (MySQL/MariaDB) for one
with a backslash.

## The family-specific columns — every non-pass, by cause

Like C2f's PostgreSQL directory, these run only under the alias and the control: their base classes
carry `#[RequiresDatabase('mysql')]` / `#[RequiresDatabase('mariadb')]`. Both controls are clean.

- **`MySql/EscapeTest::testEscapeString` and `MariaDb/EscapeTest::testEscapeString`** assert
  `escape("Hello'World") === "'Hello\'World'"`, `pdo_mysql`'s bytes. The shim emits
  `'Hello''World'` — the same string to MySQL in every escape mode, where `\'` changes meaning
  when a session has `NO_BACKSLASH_ESCAPES` on (SPEC §22.2 (cc)). **A deliberate divergence,
  recorded, not a defect.** Every other `EscapeTest` case passes, including the invalid-UTF-8 and
  NUL refusals (Illuminate's own).
- **`MySql/DatabaseMySqlConnectionTest::testLastInsertIdIsPreserved` and its
  `DatabaseEmulatePreparesMySqlConnectionTest` twin** run `DB::getPdo()->query('SELECT 1')` inside a
  `QueryExecuted` listener, to prove the key survives a query run in between. The SUBJECT of the test
  holds — `FerroMySqlConnection::insert()` reads the key inside `run()`, before the listener fires
  (C1f) — but the shim refuses `query()` by name: there is no PDO, and a `PDOStatement` cannot be
  built without one. **A real incompatibility, recorded rather than built:** code that reaches past
  Illuminate to `getPdo()->query()`/`prepare()` must use `DB::select()`/`DB::statement()` instead
  (`docs/known-incompatibilities.md`). The MariaDB directory has no such test.

## Not established

- **§15's bar.** The `ferro-*` columns are not green (the driver-name artifact), there is no demo app,
  and the Eloquent ORM's own suite is not run on any family.
- **`NO_BACKSLASH_ESCAPES` as a SERVER default** is not measured in CI: no server there is configured
  with it. The adversarial review measured it on a private MariaDB (that is how the first design was
  broken), and the shim no longer depends on the server's mode at all: `MySqlEscapeLiveTest` reads
  every literal back exactly in BOTH modes on one pinned connection.
