# testkit/dbal/triage.txt — the D18 triage of the doctrine/dbal subset (SPEC D18; E9, SPEC §22.2 (da)).
#
# Every DIFFERENCE between a Ferro column and its stock-driver control must be explained here, by an
# entry whose EXPECTATION matches what Ferro actually did — the failure type and message, or the skip.
# testkit/dbal/compare-columns.php --triage reads it after each Ferro column runs beside its control
# and FAILS the dbal-suite workflow on a difference no entry matches; ci/check-suite-triage.sh checks
# every entry and citation on every push. The format is documented at the top of compare-columns.php.
#
# Column keys: dbal<major>-<family> — dbal4-pg, dbal4-mysql, dbal4-mariadb, dbal4-sqlite, and the
# same with dbal3 (the runner's two pinned trees, 4.4.4 and 3.10.6).
#
# WHERE THE EXPECTATIONS COME FROM. The entries were collected from the recorded triage —
# docs/dbal-suite/2026-08-11-results.md (S8b's categories), 2026-09-09-a5-results.md,
# 2026-09-15-c3-6a-sqlite-results.md, 2026-10-02-c5b-dbal3-results.md — and every expectation (type and
# message) was then DERIVED from the dev container's JUnit, Ferro beside the control: PostgreSQL 16.13,
# MariaDB 10.11.14 and SQLite 3.53.2. None is from memory. MySQL 8.4 runs only on the runners and its
# recorded runs kept no JUnit, so an entry naming a dbal*-mysql column carries the expectation PostgreSQL
# and MariaDB AGREED on; where they disagree the MySQL arm is marked UNVERIFIED. A wrong expectation
# fails closed: the gate reports the observed type and message, never green.
#
# A test that fails in BOTH columns for the same cause needs no entry (the control attributes it) —
# the suite user lacking CREATE DATABASE (testIntrospectDatabaseNames, DBAL 3's testListDatabases) is
# such a case, since the control shares that user. "Same cause" is the same exception type and, for
# PHPUnit's own assertion types, the same normalised message.
#
# The vendor gates: since E9 TestUtil::isDriverOneOf() answers the family's PDO driver name in the
# Ferro column (and the real one in the control), so upstream's vendor-gated tests run in both. In
# the allowlisted subset that changed two tests (DBAL 4 testUnsignedBigIntOnMySQL now runs and PASSES
# through Ferro on MariaDB; DBAL 3 testSqliteLocateEmulation now runs, triaged below).
#
