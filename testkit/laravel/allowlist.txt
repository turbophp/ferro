# testkit/laravel/allowlist.txt — the slice of laravel/framework's tests/Integration/Database/ that
# the C2 runner executes. Paths are relative to the pinned clone.
#
# EVERY DRIVER-AGNOSTIC TOP-LEVEL FILE, enumerated rather than globbed. The directory also holds
# per-driver subdirectories (Postgres/, MySql/, MariaDb/, SqlServer/, Sqlite/) plus Fixtures/,
# Queue/ and stubs/, and a `<directory>` entry would sweep all of those in — so the list is explicit
# and the three non-test files below are named as excluded rather than silently absent.
#
# DRIVER-GATED SUBDIRECTORIES STAY OUT, and the reason has been MEASURED rather than assumed.
# Upstream's per-driver base classes skip on the DRIVER NAME:
#
#     abstract class PostgresTestCase extends DatabaseTestCase {
#         protected function defineDatabaseMigrations() {
#             if ($this->driver !== 'pgsql') { $this->markTestSkipped('Test requires a Postgres connection.'); }
#         }
#     }
#
# Under `FERRO_LARAVEL_DRIVER=pgsql` (the opt-in alias) those WOULD now run, and that is a real
# option for a later slice. It is not taken here because the alias column would then carry ~200 more
# tests than the default column, and the two columns exist precisely to be COMPARABLE — a difference
# between them has to be attributable to the driver NAME, not to a different test set.
#
# THREE TOP-LEVEL FILES ARE EXCLUDED, each because it defines no runnable test case:
#   DatabaseTestCase.php                     the abstract base (replaced by our patched copy)
#   Enums.php                                plain enum declarations
#   EloquentTransactionWithAfterCommitTests.php   a TRAIT; its class name does not match the file, so
#                                            PHPUnit reports "Class ... cannot be found" as a runner
#                                            warning if it is included (measured)
