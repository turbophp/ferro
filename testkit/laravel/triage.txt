# testkit/laravel/triage.txt — the D18 triage of the laravel/framework subset (SPEC D18; E9, SPEC §22.2 (da)).
#
# SPEC D18 calls a suite column green when it has parity with a stock-driver control and every
# Ferro-only non-pass is either upstream code branching on the driver NAME or an incompatibility
# documented in docs/known-incompatibilities.md. This file is that list for testkit/laravel-suite.sh.
# The laravel-suite workflow runs testkit/dbal/compare-columns.php --triage on every Ferro column
# against its family's stock-pdo control and FAILS on a Ferro-only non-pass no entry here covers;
# ci/check-suite-triage.sh checks every citation on every push. The format is documented at the top
# of compare-columns.php. Upstream paths are relative to the pinned laravel/framework v11.51.0
# clone, and each `upstream:` line is re-checked against it on every suite run.
#
# Column keys: laravel-<server>-<driver>, and laravel-<server>-specific-<driver> for upstream's
# family-specific directory (which runs under the stock name only):
#   laravel-pg-ferro-pgsql        laravel-pg-pgsql        laravel-pg-specific-pgsql
#   laravel-mysql-ferro-mysql     laravel-mysql-mysql     laravel-mysql-specific-mysql
#   laravel-mariadb-ferro-mariadb laravel-mariadb-mariadb laravel-mariadb-specific-mariadb
#   laravel-sqlite-ferro-sqlite   laravel-sqlite-sqlite
#
# SEEDED BY COLLECTION, NOT RE-DERIVATION: every entry is a non-pass the recorded triage already
